# 角色界面分离功能 - 测试指南

## 功能概述

本次更新将原 Form1 分离为三个独立的角色专用界面，并为 Regulator 角色添加了编辑魔女公开描述的功能。

## 已完成的功能

### 1. 三个独立的角色界面

- **Form1_Admin**: 管理员专用界面
- **Form1_Regulator**: 监管员（Meruru/Utena）专用界面
- **Form1_Warden**: 典狱长专用界面

### 2. 登录路由

登录后根据角色自动跳转到对应界面：
- Admin → Form1_Admin
- Meruru/Utena → Form1_Regulator
- Warden → Form1_Warden
- Witch → PhoneForm（图鉴界面）

### 3. Regulator 编辑描述功能

- 右键菜单：在魔女列表中右键点击，显示"编辑公开描述"和"查看详情"选项
- 权限控制：只能编辑本岛屿的魔女信息
- 编辑窗口：专门的编辑窗口，支持多行文本编辑和字数统计
