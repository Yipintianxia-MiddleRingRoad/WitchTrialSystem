# 魔女信息编辑功能说明

## 📋 功能概述

Admin 可以通过右键菜单编辑魔女的所有信息（42个字段），包括基本信息、身体特征、联系方式、教育背景、工作经历、家庭关系、个性特征、魔女信息、分配信息和时间记录。

## 🎯 设计方案

### 方案选择：复用 WitchAddForm

我们采用了**复用添加表单**的方案，将 `WitchAddForm` 改造为支持两种模式：
1. **新增模式**：添加新魔女
2. **编辑模式**：编辑现有魔女

**优点：**
- 代码复用率高，维护成本低
- 用户体验一致（添加和编辑使用相同界面）
- 所有42个字段都可以编辑
- 不需要维护两套UI代码

## 📝 使用流程

### 编辑魔女信息
1. 在 Admin 面板的数据网格中，右键点击要编辑的魔女
2. 选择"编辑魔女信息 - [魔女姓名]"
3. 打开编辑表单，所有字段已填充现有数据
4. 修改需要更改的字段
5. 点击"保存"按钮
6. 系统验证数据并更新到数据库
7. 显示成功消息，返回 Admin 面板
8. 数据网格自动刷新

### 双击查看详情
- 双击魔女记录仍然打开 A4 档案详情窗口（只读）
- 右键点击才打开编辑表单（可编辑）

## 📊 支持的字段

### 可编辑的42个字段
所有字段都可以编辑，包括：
- ✅ 基本信息（10个）
- ✅ 个人信息（8个）
- ✅ 联系方式（4个）
- ✅ 教育背景（2个，包括JSON）
- ✅ 工作经历（1个，JSON）
- ✅ 家庭关系（6个）
- ✅ 个性特征（5个）
- ✅ 魔女信息（2个）
- ✅ 时间记录（4个）

### 特殊字段处理
- **教育经历和工作经历**：以 JSON 格式存储，通过对话框编辑
- **时间戳字段**：使用 CheckBox 控制是否保存
- **岛屿和批次**：支持修改分配信息

## ⚠️ 注意事项

1. **必填字段**：姓名、魔法、状态不能为空
2. **囚犯编号**：如果修改囚犯编号，需要确保不与其他魔女重复
3. **岛屿-批次关系**：选择岛屿必须选择批次
4. **时间戳**：只有勾选的时间字段才会被更新
5. **JSON字段**：教育和工作经历的修改会完全替换原有数据

## 🗄️ 数据库脚本
