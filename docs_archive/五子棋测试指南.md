# 五子棋功能测试指南

## 前置准备

### 1. 数据库更新
执行 SQL 脚本添加五子棋积分字段：

```bash
# 在 SQL Server Management Studio 或命令行中执行
sqlcmd -S localhost -d WitchTrialWT -i add_gomoku_score_column.sql
```

或者手动执行：
```sql
USE WitchTrialWT;
ALTER TABLE wt.[User] ADD GomokuScore INT NOT NULL DEFAULT 0;
```

### 2. 准备测试账号
确保系统中至少有 2 个魔女账号用于测试对弈。

### 3. 准备背景图
确保以下图片文件存在：
- `Images/ui/gomoku_mode_bg.png` - 模式选择界面背景
- `Images/ui/gomoku_board_bg.png` - 棋盘界面背景

## 测试流程

### 测试1：页面跳转
1. 启动程序，以魔女账号登录
2. 进入手机界面
3. 点击底部左下角红色图标（第一个）
4. **预期**：进入五子棋模式选择界面

### 测试2：对手选择与密码验证
1. 在模式选择界面，点击左侧"单设备对弈"
2. 在弹出的对话框中选择对手
3. 输入**正确**的对手密码
4. **预期**：验证通过，进入棋盘界面
5. 返回重试，输入**错误**密码
6. **预期**：提示"密码错误"，无法进入

### 测试3：棋盘绘制
1. 成功进入棋盘界面
2. **预期**：
   - 左侧显示 15x15 棋盘网格
   - 棋盘上有天元和星位标记（黑点）
   - 右侧显示两位玩家信息（名称、积分）
   - 计时器显示 00:00

### 测试4：落子与轮流
1. 点击棋盘任意交叉点
2. **预期**：出现黑色棋子
3. 再次点击另一个位置
4. **预期**：出现白色棋子
5. 继续落子
6. **预期**：黑白交替出现
7. 点击已有棋子的位置
8. **预期**：无法落子

### 测试5：计时器
1. 开始游戏后观察右侧计时器
2. **预期**：
   - 当前玩家的步时每秒增加
   - 当前玩家的局时每秒增加
   - 落子后，步时重置为 00:00
   - 对手的计时器不变

### 测试6：五子连珠判定
1. 故意下出横向五子连珠
2. **预期**：弹出"XXX 获胜"提示
3. 重新开始，下出纵向五子连珠
4. **预期**：弹出获胜提示
5. 重新开始，下出斜向五子连珠
6. **预期**：弹出获胜提示

### 测试7：积分结算
1. 记录游戏前两位玩家的积分
2. 完成一局游戏（某方获胜）
3. **预期**：
   - 获胜方积分 +10
   - 失败方积分 -5（最低为 0）
4. 退出游戏，重新登录
5. **预期**：积分已保存到数据库

### 测试8：悔棋功能（魔法按钮）
1. 落子几步后，点击"魔法"按钮
2. 在确认对话框中选择"是"
3. **预期**：
   - 最后一步棋被撤销
   - 轮到上一个玩家落子
   - 弹出"时间回溯成功"提示
4. 在游戏开始前点击"魔法"按钮
5. **预期**：提示"还没有落子，无法悔棋"

### 测试9：和棋功能（伪证按钮）
1. 游戏进行中，点击"伪证"按钮
2. 在确认对话框中选择"是"
3. **预期**：
   - 游戏结束
   - 弹出"双方接受和棋"提示
   - 积分不变

### 测试10：返回与退出
1. 游戏进行中，点击右上角 X 按钮
2. **预期**：弹出确认对话框
3. 选择"否"
4. **预期**：继续游戏
5. 再次点击 X，选择"是"
6. **预期**：返回模式选择界面
7. 按 Esc 键
8. **预期**：返回手机界面

### 测试11：平局
1. 故意下满整个棋盘（15x15=225步）且无人获胜
2. **预期**：弹出"平局"提示

## 已知问题与注意事项

### 界面布局
- 当前坐标为估算值，可能需要根据实际背景图微调
- 如果背景图不存在，会显示纯色背景

### 功能限制
- 多设备联机对弈尚未实现
- 暂无音效和动画效果
- 暂无棋谱保存功能

### 性能
- 大量落子后可能需要优化绘制性能
- 计时器精度为 1 秒

## 调试技巧

### 查看积分
```sql
SELECT Username, Nickname, GomokuScore 
FROM wt.[User] 
WHERE RoleID = 2; -- 魔女角色
```

### 重置积分
```sql
UPDATE wt.[User] SET GomokuScore = 0;
```

### 查看日志
检查 `AuditLog` 表中是否有相关操作记录。

2. **音效**：添加落子、获胜、按钮点击音效
3. **动画**：添加棋子落下动画、获胜提示动画
4. **棋谱**：保存对局记录，支持复盘
5. **AI 对手**：添加单机 AI 对弈模式
6. **联机对弈**：实现多设备联机功能
7. **排行榜**：显示五子棋积分排行榜
8. **禁手规则**：可选支持五子棋禁手规则
