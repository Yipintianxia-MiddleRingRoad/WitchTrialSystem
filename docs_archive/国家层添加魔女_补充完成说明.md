## 📝 使用说明

### 添加魔女时填写时间信息
1. 切换到"时间记录"标签页
2. 勾选需要填写的时间字段
3. 在对应的日期时间选择器中选择时间
4. 未勾选的字段将不会被保存

### 时间字段的使用场景
- **被抓捕时间**：记录魔女被抓捕的具体时间
- **离开囚牢时间**：记录离开原囚牢前往魔女岛的时间
- **抵达魔女岛时间**：记录抵达魔女岛的时间
- **死亡时间**：如果魔女死亡，记录死亡时间

### 注意事项
1. 所有时间字段都是可选的
2. 可以在添加时不填写，后续通过编辑功能补充
3. 时间格式统一为：`yyyy-MM-dd HH:mm:ss`
4. 未勾选的时间字段会以 NULL 存储在数据库中
