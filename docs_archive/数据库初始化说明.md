# 数据库初始化说明

## 概述

本项目使用 SQL Server 数据库，数据库名称为 `WitchTrialWT`。

## 初始化步骤

### 1. 创建数据库和基础结构

打开 SQL Server Management Studio (SSMS)，连接到你的 SQL Server 实例，然后执行以下步骤：

#### 步骤 1：执行主数据库脚本

在 SQL Server Management Studio (SSMS) 中按以下步骤操作：

1. 连接到你的 SQL Server 实例
2. 打开并执行 `database_init.sql` 文件
3. 执行 `add_gomoku_score_column.sql` 文件
4. 执行 `create_gomoku_match_log_table.sql` 文件

`database_init.sql` 文件包含：

- 创建数据库 `WitchTrialWT`
- 创建架构 `wt`
- 创建所有基础表：
  - `wt.Role` - 角色表
  - `wt.Island` - 岛屿表
  - `wt.Batch` - 批次表
  - `wt.[User]` - 用户表
  - `wt.Witch` - 魔女表
  - `wt.UserWitch` - 用户魔女关联表
  - `wt.Audit` - 审计日志表
- 插入初始数据（角色、岛屿、批次、默认用户、魔女信息）

**注意：** 必须按顺序执行这三个 SQL 文件，否则可能会出现依赖错误。

### 2. 验证数据库

执行以下查询验证数据库是否正确创建：

```sql
-- 检查数据库是否存在
SELECT name FROM sys.databases WHERE name = 'WitchTrialWT';

-- 检查所有表
SELECT TABLE_NAME 
FROM INFORMATION_SCHEMA.TABLES 
WHERE TABLE_SCHEMA = 'wt'
ORDER BY TABLE_NAME;

-- 检查用户数据
SELECT UserID, Username, RoleID, GomokuScore 
FROM wt.[User];

-- 检查魔女数据
SELECT WitchID, Name, PrisonerNo, Magic, Status 
FROM wt.Witch;

-- 检查对局日志表结构
SELECT COLUMN_NAME, DATA_TYPE, IS_NULLABLE
FROM INFORMATION_SCHEMA.COLUMNS
WHERE TABLE_SCHEMA = 'wt' AND TABLE_NAME = 'GomokuMatchLog'
ORDER BY ORDINAL_POSITION;
```

### 3. 数据库表结构说明

#### 核心表

| 表名 | 说明 | 关键字段 |
|------|------|----------|
| `wt.Role` | 角色表 | RoleID, Name (Admin/Meruru/Warden/Witch) |
| `wt.Island` | 岛屿表 | IslandID, Name |
| `wt.Batch` | 批次表 | BatchID, IslandID, WitchCount |
| `wt.[User]` | 用户表 | UserID, Username, PasswordHash, Salt, RoleID, **GomokuScore** |
| `wt.Witch` | 魔女表 | WitchID, Name, Magic, **PrisonerNo**, Status, AvatarPath, DescriptionPublic |
| `wt.UserWitch` | 用户魔女关联 | UserID, WitchID |
| `wt.Audit` | 审计日志 | AuditID, Username, Action, Details, Timestamp |
| `wt.GomokuMatchLog` | 对局日志 | MatchID, Player1/2Username, Player1/2Name, StartTime, EndTime, Result, ScoreChange |

#### 字段说明

**User 表新增字段：**
- `GomokuScore` (INT): 五子棋积分，默认值 0

**GomokuMatchLog 表字段：**
- `MatchID`: 对局序号（自增主键）
- `Player1Username`, `Player2Username`: 玩家用户名
- `Player1Name`, `Player2Name`: 玩家显示名称（魔女名）
- `StartTime`, `EndTime`: 对局开始和结束时间
- `Player1Result`, `Player2Result`: 对局结果（Win/Lose/Draw）
- `Player1ScoreChange`, `Player2ScoreChange`: 分数变化（+10/-5/0）
- `TotalMoves`: 总步数
- `Duration`: 对局时长（秒）

## 数据库维护

### 重置数据库

如需重置数据库，执行以下命令：

```sql
USE master;
GO

-- 断开所有连接
ALTER DATABASE WitchTrialWT SET SINGLE_USER WITH ROLLBACK IMMEDIATE;
GO

-- 删除数据库
DROP DATABASE WitchTrialWT;
GO
```

然后重新执行初始化步骤。

### 备份数据库

```sql
BACKUP DATABASE WitchTrialWT
TO DISK = 'C:\Backup\WitchTrialWT.bak'
WITH FORMAT, INIT, NAME = 'Full Backup of WitchTrialWT';
GO
```

### 还原数据库

```sql
USE master;
GO

RESTORE DATABASE WitchTrialWT
FROM DISK = 'C:\Backup\WitchTrialWT.bak'
WITH REPLACE;
GO
```

### 查看对局统计

```sql
-- 查看所有对局记录
SELECT TOP 10 * FROM wt.GomokuMatchLog ORDER BY StartTime DESC;

-- 查看玩家积分排名
SELECT u.Username, w.Name AS WitchName, u.GomokuScore
FROM wt.[User] u
LEFT JOIN wt.UserWitch uw ON uw.UserID = u.UserID
LEFT JOIN wt.Witch w ON w.WitchID = uw.WitchID
WHERE u.RoleID = 4
ORDER BY u.GomokuScore DESC;

-- 查看玩家对局统计
SELECT 
    Player1Username AS Username,
    COUNT(*) AS TotalGames,
    SUM(CASE WHEN Player1Result = 'Win' THEN 1 ELSE 0 END) AS Wins,
    SUM(CASE WHEN Player1Result = 'Lose' THEN 1 ELSE 0 END) AS Losses,
    SUM(CASE WHEN Player1Result = 'Draw' THEN 1 ELSE 0 END) AS Draws
FROM wt.GomokuMatchLog
GROUP BY Player1Username
ORDER BY Wins DESC;
```

## 常见问题

### Q: 提示"数据库已存在"

A: 如果需要重新创建，先删除现有数据库（参考"重置数据库"部分）。

### Q: 提示"对象名 'wt.GomokuMatchLog' 无效"

A: 确保已执行 `create_gomoku_match_log_table.sql` 脚本。

### Q: 如何查看数据库大小？

A: 执行以下查询：

```sql
SELECT 
    DB_NAME() AS DatabaseName,
    SUM(size * 8 / 1024) AS SizeMB
FROM sys.database_files;
```

### Q: 如何清空对局日志？

A: 执行以下命令（谨慎操作）：

```sql
TRUNCATE TABLE wt.GomokuMatchLog;
GO
```
