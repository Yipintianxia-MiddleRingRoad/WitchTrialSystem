# 魔女审判系统 - 数据库初始化完整指南

## 📋 概述

本指南提供完整的数据库初始化步骤，适合首次部署或分享给其他开发者使用。

## 🎯 快速开始（4个步骤）

### 前置要求

- SQL Server 2019 或更高版本
- SQL Server Management Studio (SSMS)
- 约 100MB 磁盘空间

### 执行步骤

按以下顺序在 SSMS 中执行 SQL 脚本：

| 步骤 | 文件名 | 说明 | 执行时间 |
|------|--------|------|----------|
| 1 | `数据库完整初始化脚本_步骤1_基础结构.sql` | 创建数据库、表、初始数据 | ~30秒 |
| 2 | `数据库完整初始化脚本_步骤2_扩展字段.sql` | 添加魔女详细档案字段 | ~10秒 |
| 3 | `数据库完整初始化脚本_步骤3_导入详细数据.sql` | 导入13位魔女完整信息 | ~20秒 |
| 4 | `数据库完整初始化脚本_步骤4_更新状态.sql` | 更新魔女状态为中文 | ~5秒 |

**总计时间：约 1 分钟**

## 📝 详细说明

  - `wt.UserWitch` - 用户魔女关联表

**初始账号**（密码均为 `123456`）：

**文件**：`数据库完整初始化脚本_步骤2_扩展字段.sql`

- 基本信息：个人番号、曾用名、性别、出生日期、民族、籍贯

- 魔女相关：魔女化办法
- 其他：备注

### 步骤 3：导入详细数据

  - 待抓捕

## ✅ 验证安装

执行完所有步骤后，运行以下查询验证：

```sql
USE WitchTrialWT;
GO

-- 1. 检查表数量
SELECT COUNT(*) AS 表数量 
FROM INFORMATION_SCHEMA.TABLES 
WHERE TABLE_SCHEMA = 'wt';
-- 应该返回：8

-- 2. 检查魔女数量
SELECT COUNT(*) AS 魔女数量 FROM wt.Witch;
-- 应该返回：13

-- 3. 检查详细数据
SELECT COUNT(*) AS 已填写详细数据 
FROM wt.Witch 
WHERE PersonalNo IS NOT NULL;
-- 应该返回：13

-- 4. 检查状态
SELECT Status AS 状态, COUNT(*) AS 数量 
FROM wt.Witch 
GROUP BY Status;
-- 应该显示中文状态

-- 5. 查看所有魔女
SELECT 
    PrisonerNo AS 囚人番号,
    Name AS 姓名,
    Gender AS 性别,
    Status AS 状态,
    Magic AS 魔法
FROM wt.Witch
ORDER BY PrisonerNo;
```

## 🔧 常见问题

### Q1: 提示"数据库已存在"

**A**: 如果需要重新创建，先删除现有数据库：

```sql
USE master;
GO
ALTER DATABASE WitchTrialWT SET SINGLE_USER WITH ROLLBACK IMMEDIATE;
GO
DROP DATABASE WitchTrialWT;
GO
```

然后重新执行步骤1-4。

### Q2: 提示"字段已存在"

**A**: 步骤2会自动检查字段是否存在，如果已存在会跳过。可以直接执行步骤3。

### Q3: 数据库文件路径错误

**A**: 修改步骤1脚本中的文件路径：

```sql
FILENAME = N'你的路径\WitchTrialWT.mdf'
```

### Q4: 部分数据未导入

**A**: 检查消息窗口的输出，确认每条记录都显示"✅ 完成"。如果有失败，重新执行对应的步骤。
