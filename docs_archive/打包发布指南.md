# 打包发布指南

## 方式一：发布为独立可执行文件（推荐）

### 1. 使用命令行发布

在项目文件夹中打开命令行，执行：

```bash
# 发布为 Windows x64 独立应用（包含 .NET 运行时）
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true

# 或者发布为依赖框架的应用（需要目标电脑安装 .NET）
dotnet publish -c Release -r win-x64 --self-contained false
```

发布后的文件在：`bin\Release\net9.0-windows\win-x64\publish\`

### 2. 使用 Visual Studio 发布

1. 右键点击项目 → "发布"
2. 选择"文件夹"
3. 配置发布选项：
   - **目标框架**：net9.0-windows
   - **部署模式**：独立（Self-contained）或依赖框架（Framework-dependent）
   - **目标运行时**：win-x64
   - **文件发布选项**：
     - ✅ 生成单个文件
     - ✅ 启用 ReadyToRun 编译
     - ✅ 剪裁未使用的代码（可选）
4. 点击"发布"

## 方式二：简单打包（适合课程演示）

### 1. 编译项目

```bash
dotnet build -c Release
```

### 2. 准备发布文件夹

创建一个文件夹（如 `WitchTrialSystem_Release`），复制以下内容：

```
WitchTrialSystem_Release/
├── bin/Release/net9.0-windows/*.dll
├── bin/Release/net9.0-windows/*.exe
├── bin/Release/net9.0-windows/*.json
├── Images/                    # 复制整个文件夹
├── Fonts/                     # 复制整个文件夹
├── appsettings.example.json   # 配置文件示例
└── README.md                  # 使用说明
```

### 3. 创建安装说明

在发布文件夹中创建 `安装说明.txt`：

```
魔女审判系统 - 安装说明

1. 环境要求：
   - Windows 10/11
   - .NET 9.0 运行时（如果是独立发布则不需要）
   - SQL Server（任意版本）

2. 安装步骤：
   a. 解压所有文件到任意文件夹
   b. 复制 appsettings.example.json 为 appsettings.json
   c. 编辑 appsettings.json，配置你的数据库连接
   d. 在 SQL Server 中创建数据库（执行数据库脚本）
   e. 双击 WitchTrialSystem.exe 运行

3. 默认账号：
   - 账号：见数据库 wt.[User] 表
   - 密码：123456（首次登录会自动初始化）

4. 常见问题：
   - 如果提示缺少 .NET 运行时，请下载安装：
     https://dotnet.microsoft.com/download/dotnet/9.0
   - 如果无法连接数据库，请检查 appsettings.json 配置
```

## 方式三：制作安装包（高级）

### 使用 Inno Setup 制作安装程序

1. 下载 Inno Setup：https://jrsoftware.org/isinfo.php

2. 创建安装脚本 `setup.iss`：

```ini
[Setup]
AppName=魔女审判系统
AppVersion=1.0
DefaultDirName={pf}\WitchTrialSystem
DefaultGroupName=魔女审判系统
OutputDir=installer
OutputBaseFilename=WitchTrialSystem_Setup

[Files]
Source: "bin\Release\net9.0-windows\win-x64\publish\*"; DestDir: "{app}"; Flags: recursesubdirs

[Icons]
Name: "{group}\魔女审判系统"; Filename: "{app}\WitchTrialSystem.exe"
Name: "{commondesktop}\魔女审判系统"; Filename: "{app}\WitchTrialSystem.exe"
```

3. 编译安装脚本，生成 `.exe` 安装程序

## 发布文件大小优化

### 减小发布文件大小

1. **使用依赖框架模式**（需要目标电脑安装 .NET）：
   ```bash
   dotnet publish -c Release -r win-x64 --self-contained false
   ```
   文件大小：约 5-10 MB

2. **使用独立模式 + 剪裁**（不需要安装 .NET，但文件较大）：
   ```bash
   dotnet publish -c Release -r win-x64 --self-contained true -p:PublishTrimmed=true
   ```
   文件大小：约 50-80 MB

3. **使用单文件发布**：
   ```bash
   dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
   ```
   所有 DLL 打包成一个 .exe 文件

## 常见问题

### Q: 发布后提示找不到 DLL

A: 确保使用 `--self-contained true` 或目标电脑安装了 .NET 运行时。

### Q: 发布后图片不显示

A: 检查 .csproj 文件中是否配置了复制 Images 文件夹：
```xml
<Content Include="Images\**\*.*">
  <CopyToOutputDirectory>PreserveNewest</CopyToOutputDirectory>
</Content>
```

### Q: 发布文件太大（超过 100MB）

A: 使用依赖框架模式（`--self-contained false`），或启用代码剪裁（`-p:PublishTrimmed=true`）。

### Q: 如何更新版本号

A: 在 .csproj 文件中添加：
```xml
<PropertyGroup>
  <Version>1.0.0</Version>
  <AssemblyVersion>1.0.0.0</AssemblyVersion>
</PropertyGroup>
```
