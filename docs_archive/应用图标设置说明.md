# 应用图标设置说明

## 概述

已为所有窗体添加统一的应用程序图标支持。图标会显示在：
- 窗口左上角
- Windows 任务栏
- Alt+Tab 切换界面

## 准备图标文件

### 步骤 1：保存 PNG 图片

将你的图标图片保存为：
```
Images/ui/app_icon.png
```

建议尺寸：256x256 像素或更大（会自动缩放）

### 步骤 2：转换为 ICO 格式

Windows 应用程序需要 .ico 格式的图标文件。你可以使用以下方法之一：

#### 方法 A：在线转换（推荐）

1. 访问：https://convertio.co/zh/png-ico/
2. 上传 `Images/ui/app_icon.png`
3. 选择输出格式为 ICO
4. 下载转换后的文件
5. 将下载的文件重命名为 `app_icon.ico`
6. 放到 `Images/ui/` 文件夹中

#### 方法 B：使用 ImageMagick（命令行）

如果你安装了 ImageMagick，可以运行：

```bash
magick convert Images/ui/app_icon.png -define icon:auto-resize=256,128,64,48,32,16 Images/ui/app_icon.ico
```

#### 方法 C：使用 Paint.NET 或 GIMP

1. 用 Paint.NET 或 GIMP 打开 PNG 文件
2. 导出/另存为 ICO 格式
3. 保存到 `Images/ui/app_icon.ico`

### 步骤 3：更新项目文件

确保 ICO 文件会被复制到输出目录。打开 `WitchTrialSystem.csproj`，确认有以下配置：

```xml
<ItemGroup>
  <Content Include="Images\**\*.*">
    <CopyToOutputDirectory>PreserveNewest</CopyToOutputDirectory>
  </Content>
</ItemGroup>
```

（这个配置已经存在，无需修改）

以下窗体已添加图标支持：

1. **Form1.cs** - 管理面板

所有窗体都通过 `BLL.IconHelper.SetFormIcon(this)` 统一设置图标。

## 图标加载逻辑

`BLL/IconHelper.cs` 会按以下顺序尝试加载图标：

1. 优先加载 `Images/ui/app_icon.ico`（推荐）
2. 如果 ICO 不存在，尝试从 `Images/ui/app_icon.png` 创建图标
3. 如果都不存在，使用 Windows 默认图标

## 测试

完成上述步骤后：

1. 重新编译项目
2. 运行程序
3. 检查所有窗口的左上角和任务栏是否显示新图标

## 注意事项

- ICO 格式支持多种尺寸，建议包含 16x16、32x32、48x48、256x256 等常用尺寸
- PNG 转 ICO 时可能会有透明度问题，建议使用专业工具转换
- 如果图标不显示，检查文件路径是否正确，确保文件已复制到 bin/Debug 或 bin/Release 目录

## 其他窗体

如果还有其他窗体需要添加图标，在构造函数或 InitializeForm 方法中添加：

```csharp
BLL.IconHelper.SetFormIcon(this);
```

## 故障排除

### 问题：图标不显示

1. 检查文件是否存在：`Images/ui/app_icon.ico` 或 `Images/ui/app_icon.png`
2. 检查文件是否被复制到输出目录（bin/Debug/Images/ui/）
3. 重新编译项目（Clean + Rebuild）

### 问题：图标显示模糊

- 确保 ICO 文件包含多种尺寸
- 使用高质量的 PNG 源文件（至少 256x256）

### 问题：任务栏图标不更新

- Windows 会缓存图标，尝试：
  1. 完全关闭程序
  2. 删除 bin 目录
  3. 重新编译
  4. 重启 Windows Explorer（任务管理器 → 重启 Windows 资源管理器）
