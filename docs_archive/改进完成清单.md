## 📋 下一步操作指南

### 对于项目负责人

#### 1. 上传到 GitHub（必做）

```bash
# 在项目文件夹中打开命令行

# 初始化 Git 仓库
git init

# 添加所有文件
git add .

# 提交
git commit -m "初始提交：魔女审判系统"

# 在 GitHub 创建仓库后，关联远程仓库
git remote add origin https://github.com/你的用户名/WitchTrialSystem.git

# 推送到 GitHub
git branch -M main
git push -u origin main
```

#### 2. 邀请小组成员

1. 在 GitHub 仓库页面，点击 "Settings"
2. 点击左侧 "Collaborators"
3. 点击 "Add people"
4. 输入小组成员的 GitHub 用户名或邮箱

#### 3. 准备数据库脚本

导出数据库脚本并提交到 Git：

```bash
# 创建 Data 文件夹
mkdir Data

# 将数据库脚本放入 Data 文件夹
# - create_tables.sql（建表脚本）
# - init_data.sql（初始化数据脚本）

# 提交
git add Data/
git commit -m "添加数据库脚本"
git push
```

### 对于小组成员

#### 1. 克隆项目

```bash
# 克隆项目
git clone https://github.com/项目负责人/WitchTrialSystem.git

# 进入项目文件夹
cd WitchTrialSystem
```

#### 2. 配置环境

```bash
# 复制配置文件
copy appsettings.example.json appsettings.json

# 编辑 appsettings.json，修改数据库连接字符串
notepad appsettings.json
```

#### 3. 创建数据库

在 SQL Server Management Studio 中：
1. 执行 `Data/create_tables.sql` 创建表
2. 执行 `Data/init_data.sql` 初始化数据

#### 4. 运行项目

```bash
dotnet run
```
