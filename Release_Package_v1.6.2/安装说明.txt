  魔女审判系统 v1.6.2 - 安装说明
═══════════════════════════════════════════════════════════════

【系统要求】
- 操作系统：Windows 10/11 (64位)
- 内存：至少 4GB RAM
- 硬盘空间：至少 500MB 可用空间

【安装步骤】

1. 安装 SQL Server LocalDB
   - 运行文件夹中的 SqlLocalDB.msi
   - 按照向导完成安装
   - 安装完成后重启电脑（推荐）

2. 数据库文件（重要！已包含在发布包中）
   - 数据库文件位置：Data\WitchTrialWT.mdf 和 WitchTrialWT_log.ldf
   - ⚠️ 这两个文件包含完整的系统数据，请勿删除或修改
   - 包含内容：
     ✓ 所有用户账号和权限
     ✓ 魔女信息和审判记录
     ✓ 证物和记录数据
     ✓ 系统配置
   - 配置文件：appsettings.json（已配置好，无需修改）

3. 运行程序（两种方式）

   方式A：使用启动脚本（推荐）
   ------------------------------------------------
   - 双击 "启动程序.bat"
   - 脚本会自动检查环境并启动程序
   - 适合首次使用或遇到问题时使用
   
   方式B：直接运行
   ------------------------------------------------
   - 双击 WitchTrialSystem.exe
   - 程序会自动附加数据库文件
   - 如果提示数据库连接失败，请使用方式A

【重要注意事项】

✓ 本程序已包含 .NET 9.0 运行时，无需额外安装
✓ 首次运行可能需要较长时间加载
✓ 请勿删除 Images、Fonts、Data 等资源文件夹
✓ ⚠️ Data 文件夹中的数据库文件包含所有系统数据，绝对不能删除！
✓ 强烈建议定期备份 Data 文件夹（复制到其他位置保存）
✓ 数据库文件约 100MB，包含完整的系统数据和配置

【文件夹说明】

【故障排除】

问题1：程序无法启动
解决：- 检查是否已安装 SQL Server LocalDB
      - 使用"启动程序.bat"查看详细错误信息

问题2：数据库连接失败
解决：- 运行"启动程序.bat"自动检查和修复
      - 手动检查：打开命令提示符，输入
        sqllocaldb info MSSQLLocalDB
      - 如果显示"未找到"，运行：
        sqllocaldb create MSSQLLocalDB
        sqllocaldb start MSSQLLocalDB

问题3：数据库文件损坏或丢失
解决：- 从原始发布包中重新复制 Data 文件夹
      - 或使用之前的备份文件恢复
      - ⚠️ 不要尝试自己创建数据库，会导致所有数据丢失

问题4：图片或字体显示异常
解决：- 确保 Images 和 Fonts 文件夹完整
      - 检查文件夹权限，确保程序可以读取
