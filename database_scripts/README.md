## ⚠️ 注意事项

1. **备份数据库**：执行前建议先备份数据库
2. **执行顺序**：必须按顺序执行（先添加字段，再导入数据）
3. **重复执行**：如果字段已存在，step1 会报错，可以跳过
4. **数据覆盖**：UPDATE 语句会覆盖现有数据

## 🔧 故障排除

### 问题：字段已存在

如果提示字段已存在，说明之前已经执行过 step1，可以直接执行 step2 和 step3。

### 问题：找不到记录

确保数据库中已有 13 位魔女的基本记录（PrisonerNo 658-670）。

### 问题：日期格式错误

确保 SQL Server 的日期格式设置正确，脚本使用 `YYYY-MM-DD` 格式。
