# 数据库部署说明

## 方法：使用数据库文件附加

本项目提供完整的数据库文件（.mdf 和 .ldf），可以直接附加到 SQL Server。

---

## 📁 数据库文件位置

项目根目录的 `Data/` 文件夹中包含：
- `WitchTrialWT.mdf` - 数据库主文件
- `WitchTrialWT_log.ldf` - 日志文件

---

## 🚀 部署步骤

### 步骤1：复制数据库文件

将 `Data/` 文件夹中的两个文件复制到你的 SQL Server 数据目录。

**常见的 SQL Server 数据目录：**
```
C:\Program Files\Microsoft SQL Server\MSSQL16.MSSQLSERVER\MSSQL\DATA\
D:\Program Files\Microsoft SQL Server\MSSQL16.MSSQLSERVER\MSSQL\DATA\
```

> 💡 **如何找到你的数据目录：**
> 1. 打开 SSMS
> 2. 右键任意数据库 -> 属性 -> 文件
> 3. 查看"路径"列，就是你的数据目录

### 步骤2：附加数据库

**方法A：使用 SSMS 图形界面（推荐）**

1. 打开 SQL Server Management Studio (SSMS)
2. 连接到你的 SQL Server 实例
3. 右键"数据库" -> "附加"
4. 点击"添加"按钮
5. 浏览到你复制的 `WitchTrialWT.mdf` 文件
6. 点击"确定"
7. 系统会自动找到对应的 `.ldf` 文件
8. 点击"确定"完成附加

**方法B：使用 SQL 脚本**

1. 打开 `database_scripts/attach_database.sql`
2. **修改文件路径**为你实际复制的位置：
   ```sql
   CREATE DATABASE [WitchTrialWT] ON 
   (FILENAME = 'C:\你的路径\WitchTrialWT.mdf'),
   (FILENAME = 'C:\你的路径\WitchTrialWT_log.ldf')
   FOR ATTACH;
   ```
3. 在 SSMS 中执行脚本

### 步骤3：验证数据库

执行以下查询验证数据是否正确：

```sql
USE WitchTrialWT;
GO

-- 查看所有表
SELECT TABLE_SCHEMA, TABLE_NAME 
FROM INFORMATION_SCHEMA.TABLES 
WHERE TABLE_TYPE = 'BASE TABLE'
ORDER BY TABLE_SCHEMA, TABLE_NAME;

-- 查看魔女数量
SELECT COUNT(*) AS 魔女总数 FROM wt.Witch;

-- 查看用户数量
SELECT COUNT(*) AS 用户总数 FROM wt.[User];

-- 查看测试账号
SELECT Username, RoleName 
FROM wt.[User] u
JOIN wt.Role r ON u.RoleID = r.RoleID;
```

### 步骤4：配置应用程序

编辑项目根目录的 `appsettings.json`，修改连接字符串：

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=.;Database=WitchTrialWT;Trusted_Connection=True;TrustServerCertificate=True;"
  }
}
```

> 💡 根据你的 SQL Server 配置修改 `Server=.` 部分：
> - 本地默认实例：`Server=.` 或 `Server=localhost`
> - 命名实例：`Server=.\SQLEXPRESS`
> - 远程服务器：`Server=192.168.1.100`

### 步骤5：运行程序

```bash
dotnet run
```

使用测试账号登录：
- 用户名: `admin`
- 密码: `123456`

## ⚠️ 常见问题

### 问题1：附加失败 - 文件正在使用

**原因**：数据库文件被其他进程占用

**解决方法**：
```sql
-- 先分离数据库
USE master;
GO
ALTER DATABASE [WitchTrialWT] SET SINGLE_USER WITH ROLLBACK IMMEDIATE;
EXEC sp_detach_db 'WitchTrialWT';
GO
```

### 问题2：附加失败 - 权限不足

**原因**：SQL Server 服务账户没有文件访问权限

**解决方法**：
1. 右键数据库文件 -> 属性 -> 安全
2. 添加 `NT SERVICE\MSSQLSERVER` 用户
3. 给予"完全控制"权限

### 问题3：附加失败 - 版本不兼容

**原因**：数据库文件版本高于当前 SQL Server 版本

**解决方法**：
- 升级你的 SQL Server 到 2019 或更高版本
- 或者使用 `database_init.sql` 重新初始化数据库

### 问题4：连接失败 - 找不到数据库

**检查清单**：
1. 确认数据库已成功附加（在 SSMS 中能看到 WitchTrialWT）
2. 确认 `appsettings.json` 中的连接字符串正确
3. 确认 SQL Server 服务正在运行
4. 确认防火墙允许 SQL Server 端口（默认1433）
