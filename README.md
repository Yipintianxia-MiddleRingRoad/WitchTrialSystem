# 🎮 魔女审判系统 - WitchTrialSystem

> **基于《魔法少女的魔女审判》游戏囚犯管理数据库系统**


## 📖 项目简介

本系统是一个基于 **C# WinForms** 开发的数据库管理系统，灵感来源于游戏《魔法少女的魔女审判》。系统模拟了一个魔女审判岛屿的管理体系，实现了从国家层到普通魔女的四层权限管理架构，包含完整的魔女档案管理、五子棋对局系统、操作日志审计等功能。

### 🎯 核心特色

- ✨ **四层权限体系** - 国家层(Admin/RoleID=1) → 监管员(Meruru/RoleID=2) → 典狱长(Warden/RoleID=3) → 普通魔女(Witch/RoleID=4)
- 🏝️ **双岛屿架构** - 支持多岛屿、多批次的魔女管理
- 📋 **43字段完整档案** - 涵盖个人信息、教育经历、工作经历、家庭背景、时间记录等
- 📚 **完整图鉴系统** ⭐NEW - 人物、证物、记录、地图、规定五大图鉴，Markdown文档渲染
- ⚖️ **审判投票系统** - 完整的魔女审判流程，7个状态流转，支持单机多账号投票
- 🏛️ **处刑平台管理** - 49个处刑台动态管理，升起/返回操作，移动日志记录
- 📊 **可视化大屏** - LiveCharts图表展示，实时数据统计，魔女分布分析
- 🎲 **五子棋对局系统** - 内置积分系统和对局日志
- 🔐 **完善的安全机制** - 密码加盐哈希、操作日志审计、权限隔离
- 📸 **照相功能** - 魔女手机界面照相功能
- 🎙️ **录音功能** ⭐NEW - 魔女手机界面录音功能，支持暂停/继续/停止，自动保存
- 💬 **对话功能** ⭐NEW - 角色间互相聊天系统，支持本地聊天记录存储
- 🎨 **现代化UI设计** - 自适应布局、卡片式图鉴、手机界面模拟、自定义字体

## 🚀 v2.0 重大更新 - 审判系统与处刑平台

### ⚖️ 审判投票系统（全新功能）

完整还原《魔女的审判》游戏中的审判流程，实现了从创建审判到处刑执行的完整生命周期管理：

#### 核心功能
- 🎯 **审判会话管理** - 典狱长创建审判，选择参与魔女
- 📢 **通知系统** - 自动发送审判通知，魔女登录时弹窗提醒
- 🗳️ **投票系统** - 魔女投票选择处刑对象，实时显示投票进度
- 📊 **投票结果统计** - 典狱长查看投票结果，宣布处刑对象
- ✅ **处刑确认** - 魔女确认处刑对象，播放音效提醒
- 🔘 **处刑执行** - 魔女点击处刑按钮，完成审判流程

#### 技术亮点
- ✨ **7个状态流转** - Pending → Voting → Confirmed → Executing → Completed
- 🔄 **单机多账号支持** - 投票后可关闭窗口，切换账号继续投票
- 💾 **状态持久化** - 所有状态保存到数据库，支持断点续传
- 🔔 **实时通知** - 登录时自动检查未读通知，弹窗提醒

#### 数据库设计
- **TrialSession** - 审判会话表（11个字段）
- **TrialParticipant** - 审判参与者表（9个字段）
- **TrialNotification** - 审判通知表（6个字段）

### 🏛️ 处刑平台管理系统（全新功能）

实现了49个处刑台的动态管理，模拟处刑台升起到审判庭的完整流程：

#### 核心功能
- 🎪 **49个处刑台管理** - 每个岛屿49个处刑台，编号1-49
- ⬆️ **处刑台升起** - 从原位（1-49）升起到审判庭（50号位）
- ⬇️ **处刑台返回** - 从审判庭返回到原位
- 🔧 **刑具管理** - 管理每个处刑台的刑具信息（名称、类型、描述）
- 📝 **移动日志** - 记录所有处刑台移动历史，支持手动输入时间
- 🔍 **日志查询** - 按日期范围、处刑台编号筛选移动记录

#### 技术亮点
- 🎯 **位置管理** - HomePosition（原位1-49）+ CurrentPosition（当前位置1-50）
- 🕐 **时间管理** - 支持当前时间自动记录 + 手动输入精确时间
- 🔒 **匿名记录** - 移动日志不记录操作人，保护隐私
- 🏝️ **岛屿隔离** - 典狱长只能管理所属岛屿的处刑台

#### 数据库设计
- **ExecutionPlatform** - 处刑台表（11个字段）
- **PlatformMovementLog** - 处刑台移动记录表（10个字段）

## 🚀 快速开始

### 环境要求

- ✅ Windows 10/11
- ✅ .NET 9.0 SDK
- ✅ SQL Server 2022 或更高版本
- ✅ Visual Studio 2022 (推荐) 或 VS Code 或 Kiro / Cursor 

### 安装步骤

#### 1️⃣ 克隆项目

```bash
git clone https://github.com/yourusername/WitchTrialSystem.git
cd WitchTrialSystem
```

#### 2️⃣ 配置数据库

```bash
# 使用 SQL Server Management Studio (SSMS) 执行
sqlcmd -S localhost -i database_scripts/database_init.sql
```

或者在 SSMS 中：
1. 打开 `database_scripts/database_init.sql`
2. 连接到你的 SQL Server 实例
3. 执行脚本（会自动创建数据库 `WitchTrialWT`）

#### 3️⃣ 配置连接字符串

编辑 `appsettings.json`：

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=.;Database=WitchTrialWT;Trusted_Connection=True;TrustServerCertificate=True;"
  },
  "AppSettings": {
    "DefaultPassword": "123456"
  }
}
```

> 💡 根据你的 SQL Server 配置修改连接字符串

#### 4️⃣ 添加魔女头像（可选）

将魔女头像图片放入 `Images/` 文件夹，命名格式：`囚犯编号.jpg`

例如：`001.jpg`, `002.jpg`, `003.jpg` ...

#### 5️⃣ 编译运行

```bash
# 使用 .NET CLI
dotnet restore
dotnet build
dotnet run

# 或者在 Visual Studio 中按 F5 运行
```

#### 6️⃣ 登录系统

使用测试账号登录：
- 用户名: `admin`
- 密码: `123456`
