# 🎮 魔女审判系统 - WitchTrialSystem

> **基于《魔法少女的魔女审判》游戏囚犯管理数据库系统**


## 📖 项目简介

本系统是一个基于 **C# WinForms** 开发的数据库管理系统，灵感来源于游戏《魔法少女的魔女审判》。系统模拟了一个魔女审判岛屿的管理体系，实现了从国家层到普通魔女的四层权限管理架构，包含完整的魔女档案管理、五子棋对局系统、操作日志审计等功能。

### 🎯 核心特色

- ✨ **四层权限体系** - 国家层(Admin) → 监管员(Meruru) → 典狱长(Warden) → 普通魔女(Witch)
- 🏝️ **双岛屿架构** - 支持多岛屿、多批次的魔女管理
- 📋 **42字段完整档案** - 涵盖个人信息、教育经历、工作经历、家庭背景等
- 🎲 **五子棋对局系统** - 内置积分系统和对局日志
- 🔐 **完善的安全机制** - 密码加盐哈希、操作日志审计、权限隔离
- 📊 **A4版式档案打印** - 专业的魔女档案打印预览
- 🎨 **现代化UI设计** - 自适应布局、卡片式图鉴、友好的用户体验

## 🎨 核心功能

### 1️⃣ 魔女档案管理

- **完整档案查看** - A4版式布局，42字段完整展示
- **档案编辑** - 支持所有字段的编辑和验证
- **教育经历管理** - 动态添加、编辑、删除教育记录
- **工作经历管理** - 动态添加、编辑、删除工作记录
- **批量导入** - 支持SQL脚本批量导入魔女数据
- **头像管理** - 自动加载囚犯编号对应的头像

### 2️⃣ 魔女图鉴系统

- **卡片式展示** - 美观的卡片布局
- **分页浏览** - 支持上一页/下一页
- **搜索筛选** - 按姓名、编号、状态筛选
- **权限过滤** - 根据角色自动过滤可见数据

### 3️⃣ 五子棋对局系统

- **15×15标准棋盘** - 完整的五子棋游戏
- **积分系统** - 胜+30分，负-10分，平+5分
- **对局日志** - 记录所有对局详情
- **排行榜** - 按积分排序显示
- **对局筛选** - 查看全部/我的/指定玩家对局

### 4️⃣ 权限管理系统

- **四层权限** - Admin > Meruru > Warden > Witch
- **数据隔离** - 基于岛屿ID的数据过滤
- **操作审计** - 记录所有关键操作
- **密码安全** - SHA256 + Salt 加密存储

### 5️⃣ 国家层特殊功能

- **添加魔女** - 创建新魔女档案并自动生成账号
- **编辑档案** - 修改魔女的所有信息
- **查看日志** - 审计所有用户操作
- **跨岛屿管理** - 查看和管理所有岛屿数据

## 🚀 快速开始

### 环境要求

- ✅ Windows 10/11
- ✅ .NET 9.0 SDK
- ✅ SQL Server 2022 或更高版本
- ✅ Visual Studio 2022 (推荐) 或 VS Code 或 Kiro / Cursor 

### 安装步骤

#### 1️⃣ 克隆项目

```bash
git clone https://github.com/yourusername/WitchTrialSystem.git
cd WitchTrialSystem
```

#### 2️⃣ 配置数据库

```bash
# 使用 SQL Server Management Studio (SSMS) 执行
sqlcmd -S localhost -i database_scripts/database_init.sql
```

或者在 SSMS 中：
1. 打开 `database_scripts/database_init.sql`
2. 连接到你的 SQL Server 实例
3. 执行脚本（会自动创建数据库 `WitchTrialWT`）

#### 3️⃣ 配置连接字符串

编辑 `appsettings.json`：

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=.;Database=WitchTrialWT;Trusted_Connection=True;TrustServerCertificate=True;"
  },
  "AppSettings": {
    "DefaultPassword": "123456"
  }
}
```

> 💡 根据你的 SQL Server 配置修改连接字符串

#### 4️⃣ 添加魔女头像（可选）

将魔女头像图片放入 `Images/` 文件夹，命名格式：`囚犯编号.jpg`

例如：`001.jpg`, `002.jpg`, `003.jpg` ...

#### 5️⃣ 编译运行

```bash
# 使用 .NET CLI
dotnet restore
dotnet build
dotnet run

# 或者在 Visual Studio 中按 F5 运行
```

#### 6️⃣ 登录系统

使用测试账号登录：
- 用户名: `admin`
- 密码: `123456`

## 🎯 使用场景

### 场景1：管理员添加新魔女

1. 使用 `admin` 账号登录
2. 点击"添加魔女"按钮
3. 填写魔女的基本信息（姓名、魔法、状态等）
4. 填写详细信息（教育、工作、家庭等）
5. 选择岛屿和批次
6. 点击"保存"，系统自动创建魔女档案和用户账号

### 场景2：监管员查看岛屿魔女

1. 使用 `meruru` 账号登录
2. 自动显示所属岛屿的魔女列表
3. 双击魔女查看详细档案（只读）
4. 点击"魔女图鉴"浏览卡片式展示

### 场景3：魔女参与五子棋对局

1. 使用 `witch001` 账号登录
2. 点击"五子棋对局"按钮
3. 选择对手
4. 开始对局，系统自动记录结果和积分变化
5. 点击"五子棋日志"查看历史对局

### 场景4：管理员编辑魔女档案

1. 使用 `admin` 账号登录
2. 选择要编辑的魔女
3. 点击"编辑信息"按钮
4. 修改任意字段（支持42个字段）
5. 添加/编辑/删除教育和工作经历
6. 点击"保存"，数据通过存储过程更新到数据库
