# 脚本归档说明

本文件夹包含项目开发过程中使用的 PowerShell 脚本和其他辅助脚本。

## 脚本列表

### PowerShell 脚本

#### 批次管理
- **check_batch_status.ps1** - 快速检查批次状态
- **快速检查批次状态.ps1** - 快速检查批次状态（中文版）
- **reset_batch_passwords.ps1** - 重置批次密码

#### 数据库管理
- **执行数据库清理.ps1** - 执行数据库清理操作

#### 图片管理
- **rename_images_to_prisoner_no.ps1** - 将图片重命名为囚犯编号

### 文本文件

- **数据库命令整理后11_20.txt** - 数据库命令整理（11-20）
- **终止程序的命令.txt** - 终止程序的命令
- **database_structure_temp.txt** - 数据库结构临时文件
