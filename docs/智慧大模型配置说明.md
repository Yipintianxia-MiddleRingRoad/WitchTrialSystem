# 智慧大模型配置说明

## 📖 功能介绍

在Admin界面添加了"🤖 智慧大模型"按钮，集成豆包1.6大模型，可以通过AI助手了解项目信息。系统会自动加载项目文档作为知识库。

## 🔧 配置步骤

### 1. 配置 appsettings.json

打开项目根目录的 `appsettings.json` 文件，找到 `DouBaoAI` 配置节：

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=.;Database=WitchTrialWT;Trusted_Connection=True;TrustServerCertificate=True;"
  },
  "AppSettings": {
    "DefaultPassword": "123456"
  },
  "DouBaoAI": {
    "ApiKey": "YOUR_API_KEY_HERE",      // ← 替换为你的API Key
    "ModelId": "YOUR_MODEL_ID_HERE",    // ← 替换为你的Model ID
    "Enabled": true
  }
}
```

**示例配置**：

```json
{
  "DouBaoAI": {
    "ApiKey": "sk-1234567890abcdef1234567890abcdef",
    "ModelId": "ep-20241207-abcdef",
    "Enabled": true
  }
}
```

### 2. 保存并重启应用

## 🎮 使用方法

1. 使用 `admin` 账号登录
2. 点击工具栏的 **"🤖 智慧大模型"** 按钮
3. 输入问题，例如：
   - "这个系统有几个权限层级？"
   - "数据库有多少张表？"
   - "审判投票系统是怎么工作的？"

## 📚 知识库

系统自动加载6个核心文档：README.md、项目架构说明.md、数据库结构文档.md、系统界面跳转与权限层级说明.md、四层权限体系说明.md、CHANGELOG.md

## 🐛 常见问题

**Q: 提示"请先配置API Key"**  
A: 检查 appsettings.json 中的配置，确保不是默认值

**Q: API请求失败**  
A: 检查API Key和Model ID是否正确，网络是否正常
