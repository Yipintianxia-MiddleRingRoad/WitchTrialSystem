### 四、数据查询SQL设计

```sql
-- 1. 全局状态统计
SELECT Status, COUNT(*) as Count
FROM wt.Witch
GROUP BY Status;

-- 2. 岛屿状态统计
SELECT i.Name as IslandName, w.Status, COUNT(*) as Count
FROM wt.Witch w
JOIN wt.Island i ON w.IslandID = i.IslandID
GROUP BY i.Name, w.Status;

-- 3. 批次人数统计
SELECT 
    b.IslandID,
    b.LocalBatchID,
    COUNT(w.WitchID) as CurrentCount,
    13 as MaxCapacity
FROM wt.Batch b
LEFT JOIN wt.Witch w ON b.BatchID = w.BatchID
GROUP BY b.IslandID, b.LocalBatchID
ORDER BY b.IslandID, b.LocalBatchID;

-- 4. 批次状态矩阵
SELECT 
    b.LocalBatchID,
    w.Status,
    COUNT(w.WitchID) as Count
FROM wt.Batch b
LEFT JOIN wt.Witch w ON b.BatchID = w.BatchID
GROUP BY b.LocalBatchID, w.Status
ORDER BY b.LocalBatchID;

-- 5. 趋势数据（如果有时间字段）
SELECT 
    CAST(CaptureTime AS DATE) as Date,
    COUNT(*) as Count
FROM wt.Witch
WHERE CaptureTime >= DATEADD(DAY, -30, GETDATE())
GROUP BY CAST(CaptureTime AS DATE)
ORDER BY Date;
```

### 七、我的推荐 ⭐

**最佳方案组合**：

1. **顶部**：3个统计卡片（总人数、岛屿数、批次数）
2. **中上**：全局状态饼图（大而醒目）
3. **中间**：两个岛屿的环形图并排（对比清晰）
4. **中下**：批次容量柱状图（横向对比）
5. **底部**：批次状态热力图（详细数据）
6. **可选**：趋势折线图（如果有时间数据）

**优点**：

- ✅ 信息层次清晰（从宏观到微观）
- ✅ 视觉冲击力强（饼图+环形图+柱状图+热力图）
- ✅ 实用性高（一眼看出问题批次）
- ✅ 技术可行（ScottPlot完全支持）
- ✅ 性能优秀（WinForms原生，无需浏览器）
