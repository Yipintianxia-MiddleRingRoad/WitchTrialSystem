## 使用建议

### 日常开发
- 查看核心文档：直接在根目录查看
- 执行数据库脚本：使用 `database_scripts/` 文件夹中的脚本
- 查看历史文档：访问 `docs_archive/` 文件夹

### 查找历史资料
1. **SQL 脚本**: 查看 `sql_archive/README.md` 了解分类
2. **功能文档**: 查看 `docs_archive/README.md` 了解分类
3. **辅助脚本**: 查看 `scripts_archive/README.md` 了解分类

### 添加新文件
- **新的 SQL 脚本**: 放入 `database_scripts/` 文件夹
- **新的核心文档**: 放在根目录
- **新的功能说明**: 考虑是否需要，或放入 `docs_archive/`

---

## 注意事项

1. **不要删除归档文件夹**: 虽然是历史文件，但可能需要参考
2. **保持根目录整洁**: 新文件应该放在合适的位置
3. **定期整理**: 建议每个版本发布后整理一次
4. **备份重要文件**: 整理前已确认所有文件都已移动，未丢失
