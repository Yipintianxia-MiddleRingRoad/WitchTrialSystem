# WitchTrialSystem 快速开始指南

## 🚀 快速部署（5分钟搞定）

### 1️⃣ 环境准备
确保已安装：
- .NET 8.0 Runtime 或 SDK
- SQL Server 2019+ (推荐使用 LocalDB)

### 2️⃣ 配置数据库
```bash
# 1. 复制配置文件
copy appsettings.example.json appsettings.json

# 2. 编辑 appsettings.json，修改连接字符串
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=.;Database=WitchTrialWT;Trusted_Connection=True;TrustServerCertificate=True;"
  }
}
```

### 3️⃣ 初始化数据库
在 SQL Server Management Studio 中执行：
```sql
-- 主脚本（包含所有必要功能）
database_init.sql
-- 添加五子棋功能
add_gomoku_score_column.sql
-- 创建对局日志表
create_gomoku_match_log_table.sql
```

### 4️⃣ 启动应用
```bash
dotnet run
```

## 🔧 常见问题

### Q: 图片不显示？
**A**: 确保 `Images/` 文件夹包含所有必要的背景图片

### Q: 字体显示异常？
**A**: 检查 `Fonts/方正小标宋简.ttf` 文件是否存在

### Q: 数据库连接失败？
**A**: 检查 `appsettings.json` 中的连接字符串和 SQL Server 服务状态
