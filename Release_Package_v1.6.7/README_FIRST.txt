【快速开始】

第一步：安装 SQL Server LocalDB
  1. 双击运行 "SQL2022-SSEI-Expr.exe"
  2. 选择"基本"全套选项
  3. 勾选"LocalDB"选项
  4. 完成安装后重启电脑

第二步：一键启动程序
  1. 双击运行 "一键安装.bat"
  2. 脚本会自动配置数据库
  3. 程序启动后即可使用

第三步：登录系统
  - 用户名: admin
  - 密码: 123456

【系统要求】

✓ Windows 10/11
✓ SQL Server 2022 Express LocalDB
✓ .NET 9.0 运行时（已内置在 exe 中）

【重要提示】

⚠️ 首次运行一键安装.bat 时，建议以管理员身份执行
⚠️ 必须先安装 SQL Server LocalDB，再运行一键安装.bat
⚠️ 安装完成后需要重启电脑才能正常使用

【故障排除】

如果一键安装失败，请：
1. 查看 "安装说明.txt" 中的常见问题
2. 查看 "批处理脚本修改说明.txt" 了解脚本工作原理
3. 确保 SQL Server LocalDB 已正确安装
4. 尝试以管理员身份重新运行一键安装.bat
